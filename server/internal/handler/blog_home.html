一条命令
博客就跑起来了

没有 PHP，没有 MySQL，没有 Redis。一个二进制文件，一个 SQLite 数据库。

  1. 下载二进制

    Linux / Windows，约 13MB

  2. 设置密码，启动

    一条命令，指定端口和数据库路径

  3. Nginx 反代 + HTTPS

    certbot 签证书，生产就绪

  4. 开始写作

    拖文件、发消息、用编辑器——随你

$ terminal
# 下载（Linux amd64）
curl -LO https://aiklog.cn/dist/aiklog-linux-amd64
chmod +x aiklog-linux-amd64

# 启动
AIKMAP_ADMIN_PASSWORD='your-password' \
  ./aiklog-linux-amd64 \
  -addr 127.0.0.1:8780 \
  -db ./data/aiklog.db

# 访问
# → 博客: https://yourdomain.com/blog
# → 控制台: https://yourdomain.com/#/desk
# → 健康: GET /api/v1/health
