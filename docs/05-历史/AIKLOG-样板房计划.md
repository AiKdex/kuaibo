## 二、样板房要长什么样

访问者打开 `aiklog.com` 应在 10 秒内明白：这是能装的博客系统。

| 区块 | 内容 | 来源 |
|---|---|---|
| 首页 / 博客 | 已发布文章列表（公开视图 `#/blog?view=public`） | AiKmap 公开博客 |
| 文章 1 | 《爱库录是什么》产品介绍 | 手工 |
| 文章 2 | 《插件协议 v1.1 导读》技术向 | 手工 |
| 文章 3–5 | Aikdex 投递样例（职场/政策摘要） | 采集投递 |
| 文章页 | 启用 `blog-meta-footer` 插件 | 内置 |
| 侧栏/脚注 | GitHub 链接 + 安装一句 + 本页由爱库录生成 | 有挂载点后补 |
| 页脚/站点设置 | 标题「爱库录」、简介、logo、外链 | 待上游站点设置 |

**自检：** 匿名可读、RSS 可订、文章页有元信息插件、无登录墙。
