留白的力量：为什么顶级品牌都懂得「少即是奢」

精华 设计随笔 配色 阅读约 14 分钟

真正的奢华从不喧哗。当你走进 Hermès 的橱窗，最先注意到的不是商品，而是商品周围那片恰到好处的空——这正是今天想聊的主角：留白。

留白不是「什么都没有」，而是「刻意不放任何东西」。前者是空缺，后者是设计。

一、橱窗的呼吸感

Hermès 每季橱窗只陈列 3-5 件单品，其余空间全部让给光影。对比快时尚品牌「塞满即卖点」的逻辑，这种克制反而抬高了单品的心理价格。

二、幻灯片上的黄金比例

Apple 发布会的 Keynote 常年维持一个朴素的规则：正文不超过 12 个字，其余全是产品特写与纯色底。具体拆下来有三条：

  • 信息密度让位于视觉焦点，一页只说一件事；
  • 边距永远大于内容高度的 1/3，制造「被包裹」的安全感；
  • 强调只用一个颜色，其余全部中性灰阶。

三、屏幕上的留白怎么量化

落到执行层，我们用两个参数控制页面密度：栏宽上限 72ch，段间距取正文字号的 0.75em。再配合克制的对比度策略：

/* 正文与背景对比度 ≥ 7:1，辅助文字 ≥ 4.5:1 */
--text-main:  #243447;  /* on #f4f6f8 → 10.9:1 */
--text-muted: #7a8699;  /* on #f4f6f8 →  4.6:1 */

留白是一种把钱花在看不见的地方的奢侈——而观众恰恰感受得到。
