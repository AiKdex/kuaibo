当设计系统开始「不讲道理」——新粗野主义在 Web 上的实践

陈 陈野
2026-09-12 发布 3,482 阅读 128 赞 12 分钟

过去十年，Web 设计的主流语汇可以概括成一句话：让一切变软。圆角从 4px 涨到 16px，阴影从硬边变成 20px 模糊，配色从纯色退到低饱和渐变，连按钮都要带一点「发光」。这套语汇很舒服，舒服到我们已经忘了它只是一种选择。

新粗野主义（Neubrutalism）走的是完全相反的方向。它把 2010 年代早期那些被淘汰的粗糙做法重新捡回来，但用现代的方式重组：粗黑边框、无模糊硬阴影、高饱和撞色、零圆角、超大字号。它不追求「优雅」，它追求「被看见」。

柔和的设计让人放松，硬朗的设计让人停下。博客的第一要务从来不是让人放松，而是让人停下。

— 某个凌晨三点的自我说服

一、先把「丑」这个标签摘掉

很多人第一次看到这类界面会本能地皱眉，觉得「太吵」「太土」。但如果你把它的构成拆开看，会发现它的规则其实非常严格，甚至比主流的柔和风更严格：

  • 边框必须可见：3px 起步，纯黑，不透明，永远不用 `rgba(0,0,0,.08)` 这种糊弄人的淡边。
  • 阴影必须硬：偏移固定、零模糊、纯色，本质上是「第二层边框」而非光影。
  • 颜色必须敢用：底色浅，强调色饱，同一屏不超过三种强调色。
  • 圆角必须为零：任何一处 4px 圆角都会让整套语言泄气。

这些规则全部是结构性的，而不是情绪性的。换句话说，它丑不丑取决于你有没有守规则，而不是取决于风格本身。

1.1 阴影其实是边框的延伸

这是理解这套风格最关键的认知转换。传统设计中阴影负责模拟光照与层级；在新粗野主义里，阴影只负责加粗轮廓。所以它的阴影永远是一个方向、固定偏移、零模糊：

/* 错误的做法：这是柔和风 */
.card {
  box-shadow: 0 8px 24px rgba(0,0,0,.12);
  border-radius: 12px;
}

/* 正确的做法：硬阴影 + 零圆角 */
.card {
  border: 3px solid #101010;
  box-shadow: 6px 6px 0 #101010;
  border-radius: 0;
  transition: transform .12s, box-shadow .12s;
}

/* 悬停时「按下」：位移抵消阴影 */
.card:hover {
  transform: translate(6px, 6px);
  box-shadow: 0 0 0 #101010;
}

这段代码里最有意思的是 hover 状态。元素向右下移动 6px，同时阴影收缩到 0，视觉上就像被手指按进纸面。这个「按压感」是整套风格的灵魂，比任何颜色都重要。

二、可读性不靠字号，靠对比

反对者最常见的理由是「太刺眼，读不下去」。但真正导致阅读疲劳的不是撞色，而是对比度不足的正文。这套风格恰恰在这一点上比很多柔和风做得好：

  1. 正文永远用接近纯黑（`#101010`）配接近纯白（`#FFFBEF`），对比度约 18:1，远超 WCAG AAA 的 7:1。
  2. 高饱和色只出现在标签、按钮、色块上，绝不铺满正文区。大面积铺色是这套风格翻车的主要原因。
  3. 强调色最多三种，且固定语义：黄 = 主强调，粉 = 次强调，绿 = 状态。
一句话规则 高饱和用在小面积，大面积留给黑与白。颜色是标点，不是句子。

2.1 中文排版的额外注意

英文字体（Archivo Black、Space Grotesk 之类）在粗野风里表现极好，但中文没有对应的超粗字重时，容易糊成一团。实践中的折中方案是：

  • 标题用「黑体 + font-weight 900 + 轻微负字距」，字号放大到 32px 以上，靠体量而非字重取胜。
  • 正文严格 1.8 以上行高，中文比英文更吃行高。
  • 避免对中文使用 -webkit-text-stroke 描边，笔画会粘连；描边只用在英文大标题上。

三、什么时候不该用它

这才是最重要的部分。这套风格有明显的适用边界，用错地方会直接劝退用户：

  • 不适合：银行、医疗、政务类界面。用户在这些场景需要信任感，而硬朗线条传递的是「挑衅」。
  • 不适合：信息密度极高的后台表格。满屏硬边框会让表格线彻底失去层次。
  • 适合：个人博客、作品集、设计工作室、活动落地页、创意产品官网。

换句话说，它适合表达立场的地方，不适合处理业务的地方。博客恰好是前者。

最后回到最初的问题：为什么要把博客做成这样？因为写博客本身就是一件有点不讲道理的事情——花十几个小时写一篇可能只有两百人读的文章。既然行为已经足够粗野了，界面温柔给谁看？
