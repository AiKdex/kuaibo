# AI 能力开放与配额分层通用规范

> 版本：**v1.0** · 2026-09-17 · 起草基准：AiKlog 博客 AI 问答落地实例
> 适用范围：**主系统（AiWebs）／AiKdex／AiKlog（博客）／AiKbox（网盘 · WebDAV）** —— 主系统分出的三套垂直赛道 + 分发/市场方，凡对外开放 AI 能力（对话、摘要、搜索、翻译、文件理解等）一律套用本规范的身份分层、配额模型与商业化挂钩约定。

---

## 0. 一句话原则

**AI 能力默认开放体验、按身份分层限量、按套餐放大配额、全站设预算熔断。** 任何 AI 端点上线必须同时具备：身份识别、分层配额、用量落库、后台可配置四件套，缺一不得上架。

---

## 1. 身份分层（四层）

| 层 | 识别方式 | 责任边界 | 默认定位 |
|---|---|---|---|
| **游客**（匿名） | IP（X-Real-IP 优先，回落 RemoteAddr）+ 可选设备指纹 | 无账号，滥用成本最低，配额最紧 | 体验引导层：够尝到甜头，产生注册动机 |
| **登录用户** | `Authorization: Bearer <token>`（会话表校验；**可选鉴权**——无 token 或 token 无效不拒答，按游客处理） | 有账号可追踪、可封禁、可计费 | 主力消费层 |
| **站长/管理员** | 登录 + role ∈ {owner, admin} | 运营自己站点，不限或高配 | 不设障碍 |
| **授权编辑** | 登录 + 产品级授权名单（如 AiKlog `blog.authors` 白名单） | 受站长信任的协作者 | 与管理员同档或独立档 |

**关键约定**：

1. **可选鉴权**：公开 AI 端点不强制登录（保留游客体验），但服务端必须尝试解析 token——识别成功即升级到对应层配额。拒绝游客的是配额，不是鉴权。
2. **身份与配额绑定，不与功能绑定**：AI 端点保持只读/单轮语义（AiKlog 博客问答即如此），**写操作（发布/编辑/删除）永远走既有鉴权通道，不因配额放开而放宽写权限**。
3. **封禁优先**：命中滥用（人工或自动）可直接拉黑 ident（`ip:*` / `u:*`），黑名单优先于一切配额判断。

## 2. 配额模型（三层闸门）

每个 AI 调用按顺序过三道闸，任一不过即拒绝：

```
① 黑名单 → ② 突发窗口（防秒级刷） → ③ 日配额（按身份层） → ④ 全站日预算（防账单爆炸）
```

| 闸门 | 维度 | 粒度 | 语义 |
|---|---|---|---|
| 突发窗口 | per ident | 分钟级（如 5 分钟 N 次） | 防脚本秒刷；进程内存实现即可 |
| 日配额 | per ident | 自然日（站点本地时区），按身份层取值 | 游客 3 次/日、登录用户 10 次/日（默认值，后台可改） |
| 全站日预算 | per 产品 | 自然日全站总次数/总花费 | 超限**全站降级**（degraded 提示），保护站长账单与平台成本 |

**硬性规则**：

1. **计数先行**：通过闸门后、调用模型前即计数（ attempts 计入，失败也占额）——防止用报错刷免费调用。
2. **落库持久**：日配额与日预算计数必须落库（按 `日+ident+能力scope` 主键 upsert），重启不清零、可审计；突发窗口可留内存。
3. **429 语义统一**：返回体含 `code`（如 `AI_QUOTA_GUEST` / `AI_QUOTA_USER` / `AI_BUDGET_FUSE`）、人类可读提示（游客提示「登录可获得更多次数」= 注册转化钩子）、以及 `remaining` / `limit` 字段（主题/客户端可展示余量）。
4. **配额查询端点**：每个 AI 能力配一个轻量 `GET .../quota` 端点，返回当前身份的 `{limit, used, remaining}`，不做任何模型调用——主题据此渲染余量 UI。
5. **超限降级而非报错雪崩**：全站预算熔断时返回 `degraded=true` + 友好文案，前端按降级渲染（与模型不可用同一通道）。

## 3. 配置约定（后台可编辑，禁止硬编码）

所有阈值走配置中心 settings，命名统一 `<产品>.<能力>.<参数>`：

| 键 | 默认 | 说明 |
|---|---|---|
| `<p>.ai.<cap>.guest_quota` | 3 | 游客日配额（0=关闭游客使用） |
| `<p>.ai.<cap>.user_quota` | 10 | 登录用户日配额 |
| `<p>.ai.<cap>.admin_quota` | 0 | 管理员日配额（0=不限） |
| `<p>.ai.<cap>.burst_max` | 8 | 突发窗口次数 |
| `<p>.ai.<cap>.burst_window_min` | 5 | 突发窗口分钟数 |
| `<p>.ai.<cap>.daily_budget` | 200 | 全站日预算（次数；0=不限） |
| `<p>.ai.<cap>.open` | true | 能力总开关（独立于产品总开关） |

- 后台设置表单渲染时用中文标签（如「游客每日问答次数」），键名英文、展示中文——裸参数不允许出现在 UI。
- 值变更即时生效（配置中心热读），不需要重启。

## 4. 商业化挂钩（Entitlement / 套餐）

配额分层是商业化基座，套餐层在其上做**乘法**，不做加法：

```
实际配额 = 基础配额(身份层) × 套餐倍率(Entitlement)
```

| 挂钩点 | 免费版 | 付费版 | 说明 |
|---|---|---|---|
| 配额倍率 | ×1 | ×3～×N | Entitlement 层下发 `quota_multiplier` |
| 模型档位 | 轻量模型 | 高级模型 | 同一端点按套餐路由不同模型，免费版保成本 |
| 单次上限 | 800 字输入 | 更长输入/输出 | 对话长度本身也是增值项 |
| 增值包 | — | AI 次数加油包 | 次数即商品，计数表天然就是账单依据 |
| 付费闸门 | — | `tier=paid` 402 | 与应用中心 paid 插件同一闸门语义 |

**原则**：免费层必须「够用且有感知」——游客 3 次/日的意义在于让读者体验到价值并产生注册/付费动机，而不是把免费层掐死。所有配额数字都应是**后台可调的运营参数**，不是代码常量。

## 5. 用量审计与报表

- 计数表最小结构：`(day, ident, scope, hits)`，主键 `(day, ident, scope)`，upsert 累加；`ident` 形如 `u:<user_id>` / `ip:<ip>`。
- 管理端报表端点：按日聚合总次数、按层分布、Top N ident——既是运营看板，也是商业化账单的数据底座。
- 记录**能力 scope**（如 `blog_ask`），同产品多 AI 能力（问答/摘要/搜索）共享日预算但独立日配额，报表可分摊成本。

## 6. 垂直赛道映射示例

| 赛道 | AI 能力示例 | 身份/配额落点 | 商业化落点 |
|---|---|---|---|
| **AiKlog（博客）** | 读者问答（右下角对话窗）、自动摘要/标签 | 游客=读者 IP；登录=注册读者；编辑白名单同管理员 | 套餐放大问答配额；次数加油包 |
| **AiKbox（网盘 · WebDAV）** | 文件 AI 摘要/问答、语义搜索、图片理解 | API token / WebDAV 挂载凭证归属到租户→按**租户**配额（不是按人）；游客（分享链接访客）按分享 token 限额 | 按存储容量+AI 处理量双维度套餐；大文件理解走次数包 |
| **主系统（AiWebs）** | 建站 AI 模板、IM 渠道自动回复、定时发文 AI | 租户/站点级配额，站点内再按身份分层 | 平台级套餐直接决定各站点 AI 总预算 |
| **AiKdex（分发/市场）** | 市场搜索/推荐、上架材料 AI 审查 | 开发者账号配额；平台侧审核 AI 不限 | 上架增值服务（AI 审查报告、推荐位） |

**AiKbox 特别注意**：WebDAV/API token 天然是机器对机器，突发窗口应放宽、日配额按 token 归属租户计算；分享链接的匿名访客走「游客档」，且分享 token 可被站长单独停用（黑名单机制复用）。

## 7. AiKlog 落地实例（v1.0 随本规范同批实施）

- 端点：`POST /api/v1/public/blog/ask`（已有，本批补配额）+ `GET /api/v1/public/blog/ask/quota`（新增）。
- 键名（AiKlog 前缀 `blog.`）：`blog.ai_ask_guest_quota`=3 / `blog.ai_ask_user_quota`=10 / `blog.ai_ask_admin_quota`=0（不限）/ `blog.ai_ask_daily_budget`=200 / 既有 `blog.ai_ask_open` 总开关、`blogAskMax/Window`=8 次/5 分钟突发。
- 计数表：`ai_ask_usage(day, ident, scope, hits)`，scope=`blog_ask`。
- 身份：可选 Bearer → sessions 表校验 → users.role 判管理员；游客按 IP。
- 输入截断修正：按**字符**（rune）800，不再按字节。
- 管理报表：`GET /api/v1/admin/ai/usage?days=7`；站长后台「AI 用量」卡片。

## 8. 演进预留（本期不做，接口留位）

- 套餐倍率接入：`licenseEdition()` 当前恒 free，Entitlement 层建成后在此端点读取 `quota_multiplier`。
- 模型档位路由：`ai.ChatJSON` 增加档位参数。
- 全站预算按**花费**（tokens×单价）计而非次数计；需模型层回传 usage。
- 设备指纹、验证码升级挑战（配额连续触顶时叠加）。
