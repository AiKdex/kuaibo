# 应用中心壳端对接规范（v1，2026-09-16）

> 对象：AiKBox / AiKlog / AiKdex 等壳端开发方——把壳的应用中心（插件/主题/Agent Tools 市场）接到主系统统一市场。
> 定位：主系统侧对接面已全部就绪（市场索引 + target 分发 + 安装管线 + license 门禁），本文是壳端联调的操作规范与冒烟清单。
> 配套：`docs/能力插件协议-v2草案.md`、`docs/事件总线契约.md`、`docs/版本兼容契约.md`、`docs/博客插件协议.md`、`docs/AgentTools开发规范.md`、`docs/主题上架操作规范.md`。
> 权威实现：主仓 `server/internal/handler/blog_market.go`、`license.go`、`blog_plugins.go`。

---

## 1. 对接前置

1. **版本对齐**：壳端必须拉取主系统最新 main（当前含市场多壳模型 + license 门禁 + seam 接口化），**禁止壳内私有改市场协议**（协议变更由主系统 minor bump，见版本契约）。
2. **能力检查**（GET /api/v1/version）：`version` 语义化 ≥ 市场功能版；`schema` ≥ 2。
3. **配置项**（settings 或环境）：

| 配置键 | 含义 | 默认 |
|---|---|---|
| `plugin_market.index_url` | 市场索引地址（支持 `https://…` 或 `file:///…` 本地调试） | `https://aikmap.cn/market/index.json`（上游 2026-09-17 应用中心独立化后的统一索引；market.aikmap.com 归 kmap 自身使用） |
| `plugin_market.shell_id` | 本壳身份（决定 target 过滤与安装放行） | `aikmap` |
| `market.pricing_override` | 本地定价覆盖 JSON（`{"<id>":{"tier":"free|paid","price":"…","free_until":"YYYY-MM-DD"}}`） | 空 |
| `market.official_dir` | 官方 Agent Tools zip 静态目录 | `market/official` |

- **壳 ID 取值**：`aikmap`（主系统）/ `aikbox` / `aiklog` / `aikdex`，由各壳在部署配置中声明；市场条目 `target` 为空 = 兼容所有壳。

## 2. 市场索引协议（index.json）

```jsonc
{
  "schema_version": "1",
  "plugins": [ /* 博客插件 */ ],
  "themes":  [ /* 博客主题 */ ],
  "tools":   [ /* Agent 工具（对话/IM 能力包） */ ]
}
```

条目通用字段（三类结构一致）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 ID（如 `blog-comments`、`tool_im_upload`） |
| `name` / `version` / `description` / `author` | string | 展示与版本（version 须语义化） |
| `download_url` | string | 插件包 zip 地址（≤16MiB） |
| `sha256` | string | 包校验和（声明时安装强制校验） |
| `tier` | string | `free` / `paid` |
| `target` | string[] | 适用壳清单（空=全部壳） |
| `min_core_version` | string | 主系统版本下限（语义化比较） |
| `settings_schema` | array | 动态设置表单声明（驱动壳端渲染） |
| `price` / `billing_period` | string | 展示价 / `once|monthly|yearly`（仅展示，内核不结算） |
| `free_until` | string | 限免截止 `YYYY-MM-DD`（tier=paid 且未到期 → 免费放行） |
| `trial_days` | int | 试用天数（预留） |
| `quota` | object | 配额声明（预留） |

## 3. 壳端列表渲染规则

壳端调用 `GET /api/v1/blog/market`（登录）获取视图，服务端已补充三个标记：

| 标记 | 含义 | 壳端用法 |
|---|---|---|
| `applicable` | `target` 含本壳或为空 | 只渲染 `applicable=true` 的条目 |
| `installed` | 本实例已注册 | 渲染「已安装」态 |
| `effective_tier` / `limited_free` | 本地覆盖/限免合并后的实际档位 | 展示「限免中」徽标 |

- 索引服务端缓存 5 分钟；壳端刷新列表走同一端点即可。
- **判定顺序**：本地 `market.pricing_override` > 条目 `free_until` 限免 > 条目 `tier` 默认。

## 4. 安装通道

`POST /api/v1/blog/market/install`（登录）

```jsonc
// 方式 A：按市场 id（推荐）
{ "id": "blog-comments" }
// 方式 B：直接给包（调试/内测）
{ "url": "https://…/plugin.zip", "sha256": "…" }
```

安装管线（服务端自动完成）：

```
按 id 解析索引（或官方工具）→ target 校验 → 付费门禁 → 下载 zip（≤16MiB）
→ SHA-256 校验 → 解包 manifest.json（zip slip 防护）→ 版本/前端白名单校验
→ 注册（幂等 upsert）→ 200 {ok,id,name,version}
```

**zip 包结构**（必须含 `manifest.json`，任意子目录均可）：

```text
plugin.zip
└── manifest.json        # 必须，见能力插件协议 v2 §1
└── assets/…             # 前端资源（壳端自行分发，协议不强制）
```

## 5. 校验与拒绝（壳端需感知的错误）

| 场景 | 错误码 | HTTP |
|---|---|---|
| 插件不适用于本壳（target 不含 shell_id） | `MARKET_TARGET_MISMATCH` | 422 |
| 付费插件无 pro 许可证（且未限免） | `MARKET_LICENSE_REQUIRED` | 402 |
| 市场未收录该 id | `MARKET_NOT_FOUND` | 404 |
| 包 SHA-256 不匹配 | `MARKET_SHA_MISMATCH` | 422 |
| zip 非法 / 缺 manifest / zip slip | `MARKET_BAD_PACKAGE` | 422 |
| 主系统版本低于 min_core_version / schema 区间不符 | `MARKET_BAD_PACKAGE`（内部 `PLUGIN_CORE_TOO_OLD`） | 422 |
| 前端组件未在主系统注册 | `MARKET_BAD_PACKAGE`（内部 `frontend_entry 未注册`） | 422 |
| 索引不可达 / 格式非法 | `MARKET_UNREACHABLE` / `MARKET_BAD_INDEX` | 502 |

- **前端组件白名单**：主系统注册表当前含 `blog-meta-footer`（见 `blog_plugins.go` `builtinFrontendEntries`）。插件若声明 `frontend_entry`，必须先与主系统对齐（壳端自定义组件随壳构建，进入白名单需主系统 minor 版）。
- **付费门禁**：`tier=paid` 且 `free_until` 未到 → 免费放行；到期后需 pro 许可证。许可证端点：`GET /api/v1/license`（状态）、`POST /api/v1/license {"key":…}`（激活）、`DELETE /api/v1/license`（吊销）。

## 6. 官方 Agent Tools（内核内置但走标准通道）

- 元数据随内核提供（`officialTools`），下载走 `/market/official/{id}.zip` 静态服务（配置 `market.official_dir`）。
- 与第三方完全同一安装管线与收费机制（`tier` 可从 free 改 paid，付费安装需 pro license）。
- 当前官方工具：`tool_im_upload`（对话上传文件入库，默认不建公开分享）/ `tool_im_sendfile`（对话检索→建分享→回下载链接）/ `tool_im_share`（显式分享）。全部 `target` 覆盖四壳。

## 7. 联调冒烟清单（跨壳互买验收样例）

按裁定 §三，以「跨壳互买插件」为验收：AiKBox 买 AiKlog 博客插件、qiuzhi 采集插件，跑通即 P0 验收通过。

| # | 用例 | 预期 |
|---|---|---|
| 1 | 壳端配 `shell_id=aikbox` 后 GET /market | 只返回 target 含 aikbox 或为空的条目 |
| 2 | 安装 target 不含本壳的插件 | 422 `MARKET_TARGET_MISMATCH` |
| 3 | 安装 free 插件（方式 A） | 200，`installed=true`，刷新列表可见 |
| 4 | 安装 tier=paid 且无 license | 402 `MARKET_LICENSE_REQUIRED` |
| 5 | 设置 `free_until`（未来日期）后安装 paid 插件 | 200（限免放行），视图标 `limited_free=true` |
| 6 | 激活 license key 后安装 paid 插件 | 200 |
| 7 | 篡改 zip 后安装 | 422 `MARKET_SHA_MISMATCH` |
| 8 | 包内 `../` 路径 | 422 `MARKET_BAD_PACKAGE`（zip slip） |
| 9 | `min_core_version` 高于当前主系统 | 422（版本不足） |
| 10 | `frontend_entry` 未注册组件 | 422（组件需随主系统构建） |
| 11 | 配置 `index_url=file:///…` 本地调试 | 正常出列表（断网可用） |

## 8. 各壳当前状态提示

- 主系统：完整市场（三类条目 + license + 官方工具），`shell_id=aikmap`。
- AiKBox / AiKlog：对接此规范实现壳端市场页 + 安装按钮；未实现前可先直连主系统 `GET /market` 验证协议。
- AiKdex（qiuzhi）：采集插件走同一安装管线；`target` 需含 `aikdex`。
