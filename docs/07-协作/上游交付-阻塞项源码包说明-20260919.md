### 注册方式（routes.go 迁移）

主系统 `internal/handler/routes.go` 采用 CoreModules 结构体注入 + 字段 nil 门控注册：

```go
// main.go：构造模块实例并注入
mods := handler.CoreModules{
    Sources: service.NewSourceStore(db, ...),
    Collector: collectorImpl,
    WebDAV:  service.NewWebDAVStore(db, encryptor, ...),
    Digest:  service.NewDigestStore(db, ...),
    Inbox:   service.NewInboxStore(db, ...),
    Review:  service.NewReviewStore(db, ...),
    Org:     service.NewOrgStore(db, ...),
}
api := handler.New(db, cfg, b, aud, gate, files, tags, kb, agent, summarizer, impex, notify, wh, mods)
```

- 字段留空 = 对应路由组不注册（404），行为等价旧版；
- `Channel` 为第 8 字段，P1 落地时随上游发布；
- 主系统 `routes.go` 中 `if a.xxx != nil { mux.HandleFunc(...) }` 的门控片段，按需抄入 AiKlog 的 `New`。

## 阻塞 2 · 支付后端（A–G B 项）

### 需移植文件清单

| 文件 | 内容 |
|---|---|
| `internal/handler/paid_access.go` | **核心**：`blogPostsPaid`（设置付费）、`requirePaidAccess`（闸门 402）、`payNotify`（通用支付回调，HMAC 幂等签发 grant）、`issuePaidGrant`/`verifyPaidGrant`、`publicUnlock`（含付费解锁） |
| `internal/handler/article_access.go` | 密码解锁 + 定时发布（AiKlog 已有同文件，比对差异即可；主系统版含 `blogPostsAccess`/`publicUnlock`/`blogPostsSchedule`） |
| `internal/handler/license.go` | Entitlement 签发/校验（许可证；A–G 已验证） |

### 支付链路口径（paid_access.go 头部注释为权威）

1. 站长设置文章 `access_mode='paid'` + `price_cents`（分）+ `paid_preview`（none|partial|full）；
2. 公开读正文 → `requirePaidAccess` 检查：无有效 grant → **402 PAYMENT_REQUIRED**（附价格+预览策略，前端出付费页）；
3. 支付商收款后由**支付对接 tool/插件**以 HMAC 转发 `POST /api/v1/pay/notify`（`settings pay.webhook_secret` 密钥）→ 幂等签发 `grant_token` 落库 `access_grants`；
4. 公开请求带 `X-Grant-Token` 或 `?grant=` 即放行；grant 可绑定 grantee、可过期。

### DDL（ddl.sql 附后）

- `access_grants` 表（完整 CREATE）；
- `files` 扩展列：`access_mode`/`price_cents`/`paid_preview`（+ `custodian_user_id`，可选）。

### 路由（authmw 白名单）

- `POST /api/v1/pay/notify` 必须在**匿名白名单**（`authmw.go` 的公开路径判断）里，否则回调 401：
  ```go
  case p == "/api/v1/pay/notify" && r.Method == http.MethodPost:
  ```

## 三、通用移植注意

- **`password_enc`**（webdav_mounts）：主系统用 AES 加密（`internal/service/...` 的 encrypt 工具）；AiKlog 若未实现可先存明文并注释，或移植加密函数（见 webdavmount.go 引用）。
- **handler.API 字段差异**：主系统 handler 依赖 `a.db/a.cfg/a.aud/a.notify/a.wh` 等；AiKlog 的 `handler.API` 若字段名不同，按编译错误对齐（多为同名字段，去 `wh`/`aud` 等缺失字段即可，对应功能降级为不记录）。
- **`service.SystemOwnerID`**：直接使用主系统常量文件 `system.go`（值 `00000000-0000-0000-0000-000000000001`），或改为 AiKlog 自己的系统账号 ID。
- **付费闸门在公开正文链路的位置**：`requirePaidAccess` 在 `requireArticleUnlock`（密码）之后检查；AiKlog 在 `article_access.go` 同位置插入调用。

## 四、验证建议

- 移植后 `go build ./...` 通过 → 手动 curl：
  - `GET /api/v1/digest/preview`（Digest 就绪）；
  - `GET /api/v1/inbox`（Inbox 就绪）；
  - 对一篇 paid 文章匿名读 → 期望 402 + `{"price_cents":...}`；
  - 带 `X-Grant-Token` 读 → 200。
- 支付全链路（402→支付→notify→grant→放行）建议用 HMAC 脚本模拟 notify（`pay.webhook_secret` 签 HMAC-SHA256，body 含 `out_trade_no`/`file_id`/`amount`）。
