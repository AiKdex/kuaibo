## 附：复现方法（可脚本化）

```bash
# 1) 树 vs 盘面：文件集合差异
git -c core.quotepath=false ls-tree -r -z --name-only <SHA>   # 与 os.walk 盘面比对

# 2) 内容级比对（关键：区分换行噪音与真实差异）
#    自算 blob sha：sha1(b"blob %d\0" % len + content)
#    不等时再以 content.replace(b"\r\n", b"\n") 复算 → 相等即「仅换行差异」

# 3) 路由一致性
#    定义集：^func \(a \*API\) (\w+)\(        （全 handler 目录）
#    注册集：HandleFunc\("[^"]*",\s*a\.(\w+)  （routes.go）
#    差集需人工过滤：内部辅助函数 / 意图分发函数 属正常
```
