## 0. 背景与目标

B0–B10 已全部上线。现对**已上线的全部主题**做"补齐缺失页面 + 文章页加侧栏"，目标是让每个主题都具备完整的页面集合（列表页、文章页、5 个内页），且文章页都有侧栏。

**已完成盘点结论**：当前全站（SPA 0/19、SSR 0/6）的文章页**都没有侧栏**——侧栏现在只存在于列表页，文章页只有底部"相关文章"网格。这是本次最普遍的缺口。

---

## 1. 重要澄清：什么是"一致风格"（避免方向性错误）

- **不是跨主题统一**：主题本就该风格各异、版面也可以不同，不要套一个统一模板。
- **是"每个主题内部自洽"**：补齐的页面（缺失的内页、新增的文章页侧栏）必须**沿用该主题自身的设计语言**——
  - 复用它的令牌（`--th-*` / 各自前缀变量）、栅格、卡片、圆角、间距、字体；
  - 文章页侧栏的视觉与它的**列表页 `aside`** 保持一致（同一套侧栏卡片样式）；
  - 内页（Cat/Author/Tag/Archive/Search）的版面复用该主题**已有的同类页面**（例如补 Tag 页直接照抄它已有的 Cat 页，只换数据源）。
- 执行者**不要**为了"统一"而抹平各主题的个性。

## 2. 最新规范硬约束（给执行者 / 第三方的必守清单）

### 2.1 文件与注册
- SPA 主题目录：`web/src/themes/<id>/`，含 `manifest.js` + `index.js`（模块加载即 `registerTheme(theme)`）+ `<Id>View.vue` + `style.css` + `post.css`（声明 `entries.post` 时**必须**有 `post.css`）。
- **5 个必交内页**：`<Id>{Cat,Author,Tag,Archive,Search}View.vue`，用 `defineAsyncComponent` 懒加载，避免全塞首屏包。
- 注册：在 `web/src/themes/all.js` 加一行副作用导入 `import '@/themes/<id>'`；孤儿主题（未注册）先确认是否要启用。
- SSR 主题目录：`server/data/themes/<id>/`，含 `ssr.css` + `manifest.json`（必要时 `page.html`），运行时读取、**免编译热投放**；`server/data/` 被 `.gitignore` 覆盖，版本载体是交付 zip + 服务器目录。

### 2.2 文章页（本次重点）
- **文章页专属样式必须进 `post.css`**（v1.2 视图隔离，构建时自动加 `.th-<id>.th-view-post` 作用域）；列表/共享原子在 `style.css`。写错位置会跨视图泄漏。
- **文章页加侧栏**：两栏布局（正文主列 + 右侧 `<aside>` 侧栏），移动端（`@media`）降为单栏；侧栏内容为该主题已有风格（目录 / 相关文章 / 标签 / 作者卡 / 关于卡），样式复刻其列表页 `aside`。
- 文章视图根类是 `.x-post`（不是 `.x-root`），`post.css` 必须**自己再写一遍 reset 四件套**（否则继承 UA 默认 margin）。

### 2.3 契约与内容诚实性（最常被退回的点）
- 数据一律 `inject('themeContext')`，兼容 `raw?.value || raw`；**不接收 props**。
  - **契约字段（可用，空值须兜底）**：`token / path / preview / created_at`（顶层）+ `file.{name,slug,updated_at,size,author,tags,cover,excerpt}`。其中 `author / tags / cover / excerpt` 自 **v1.4.1（2026-09-17）起已真实下发**：`cover / excerpt` 空串回退、`author / tags` 空数组兜底不可省；`created_at` 顶层存在但**博客场景恒为 0**，切勿当业务时间，日期统一用 `file.updated_at`。
  - **禁止臆造**：`views / likes / comments / summary / readTime / comnum / contentHtml` 等；阅读量走 `GET /api/v1/public/blog/pv`，**不要**写 `posts[].views / view_count`。
  - ⚠️ **规范内部矛盾（务必知悉）**：§2.2 已把 `cover` 列为真实下发字段，但 §9.3 机械自检第 5 项与 `theme-lint.sh` 仍把 `.cover` 列为「契约外字段」报 `[!]`。若使用 `cover`，lint 会告警——属规范未修平的坑：要么暂不使用 `cover`，要么在 lint 第 5 项人工豁免并向规范维护者提 issue。同理 `file.author` 被 lint 注释明确**放行**（允许使用、须可选链降级）。
  - 标题派生兼容 `.md` 与 `.markdown`；分类 = `path` 首段；日期用 `file.updated_at`；链接一律 `ctx.postUrl(post)`。
  - **不重排 posts**（系统已"置顶优先 + 时间倒序"）；排序只能是读者显式操作。
  - 标签云 `v-if="tags && tags.length"` + 遍历 `{{ t.name }}` + **可点链接** `<a :href="'#/blog/tag/' + encodeURIComponent(t.name)">`（v1.2 起 `ctx.tags` 已真实下发、「不再是空数组」、`?tag=` 路由已支持，**不再是死链**）；标签页按 `(post.file?.tags || []).includes(ctx.page.tag)` 过滤。
  - 三态齐全：loading / error / 空态。AI 问答读 `reply` 且处理 429。
  - **禁止"热门 / 热榜 / 排行 / 精选 / 浏览数 / 点赞数"类文案与榜单视觉**——契约里没有热度数据，按时间排序派生的内容不能包装成"热度"。

### 2.4 路由与样式
- 宿主是 hash 路由（`#/blog?view=public`）。**内页绝对不能写 `href="#anchor"`**（如归档页年份锚点）→ 一律 `button` + `el.scrollIntoView({behavior:'smooth'})`。
- 选择器全部挂根类 / 唯一前缀，不留死 CSS；移动端断点必做。
- `manifest.tokens` 与 `style.css` 实际令牌**逐项一致**（台账对得上）。

### 2.5 验收（提交 / 交付前逐条勾）
- `npm run build` 零错误；console 无 `[themes] 主题缺少 entry/id`。
- 三态齐全；首篇不重复；点击跳 SSR 页；标签云空时隐藏；AI 读 `reply`/429 提示。
- 样式全限定在根类；**文章页专属样式在 `post.css`（视图隔离）**。
- **`bash theme-lint.sh` 退出码 0**（实际 **8 项**：①悬空类 ②死 CSS ③tokens 台账 ④hash 锚点 ⑤高危文案词 ⑥契约外字段 ⑦自建密码框/解锁逻辑 ⑧`!important` 用量>10；其中 ⑦⑧ 为 v1.3 增补，原"6 项"说法已过期）。
- 外部链接（`/api/v1/blog/feed.xml`、`/api/v1/blog/sitemap.xml`、`/api/v1/public/blog/ask`）在 `server/internal/handler/routes.go` 确有注册。
- SSR：`?theme=<id>` 两页生效且气质一致；改了 `page.html`/`ssr.css` 后免重启热生效。

## 8. 已知风险（执行时留意）

- **仓库被多会话并发编辑**：禁止 `git add -A`，提交前 `git status --short` 逐文件确认归属。
- **`server/data/` 不入库**：ssr.css/page.html 源只在交付 zip + 服务器；改了必须重打 zip，否则包与仓库漂移。
- **`npm run build` 沙箱守卫**：用 `npx vite build --outDir <临时绝对目录> --emptyOutDir false` 绕过 safe-delete 守卫。
- **SPA 文章页 `PublicView.vue` 尚未 inject themeContext / 不套 `.th-<id>`**（系统侧已知断裂）：主题仍应坚持 `ctx.postUrl(post)` 与规范契约，修系统侧即可全站生效——若发现文章页不套主题类，上报壳方而非主题侧自行 hack。
