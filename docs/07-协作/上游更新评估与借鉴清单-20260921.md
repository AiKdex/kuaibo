## 7. 移植注意事项（本次评估发现）

1. **CoreModules 静默漏模块**：上游原文警告——壳侧不核对字段清单就**不会报错**，新能力静默不可用。每次上游发布后必须人工对照。
2. **不要 merge**：上游 force-update 过历史，只能逐主题人工移植。
3. **表已建但未接线**：`org_memberships` / `org_transfers` / `space_members` / `spaces.node_id` / `custodian` 我们**已经有表**（此前为上游包预留），接 org M1/M2 时不需要再建表。
4. **uuid**：`collab.go` / `issues.go` 用 `github.com/google/uuid`——我们 `review.go` 已在用，依赖齐备；但按我方约定，**面向用户的实体 id 仍用 `newID()`**。
5. **行尾**：仓库文件行尾不统一（`routes.go`=LF、`apps_market_catalog.go`/前端=CRLF），移植时按目标文件行尾写入；改文件优先用脚本而非编辑工具。
6. **上游交付包已消化**：`上游源码交付-AiKlog同步包`（CoreModules + 支付后端）我们**已完成移植**（CoreModules 7/7 + `access_grants` + `pay/notify` 白名单），本批无需重做。
