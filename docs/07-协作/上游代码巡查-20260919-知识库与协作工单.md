### 1.1 表结构

```sql
CREATE TABLE IF NOT EXISTS issues (
  id TEXT PRIMARY KEY, space_id TEXT NOT NULL, doc_id TEXT,
  code TEXT,                                -- 空间内查重，如 REQ-001 / BUG-003
  title TEXT NOT NULL, description TEXT NOT NULL DEFAULT '',
  status TEXT NOT NULL DEFAULT 'open',      -- open|claimed|fixed|closed
  priority TEXT NOT NULL DEFAULT 'medium',  -- low|medium|high
  assignee_id TEXT, created_by TEXT NOT NULL, resolution TEXT,
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL, closed_at INTEGER
);
```

### 1.2 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/collab/issues?space=` | 列表（返回 `counts{open,claimed,fixed,closed}` + `items`） |
| POST | `/api/v1/collab/issues?space=` | 创建：`{title, description?, code?, priority?, doc_id?}` |
| GET | `/api/v1/collab/issues/{id}` | 单条 |
| PATCH | `/api/v1/collab/issues/{id}` | 编辑 |
| POST | `/api/v1/collab/issues/{id}/transition` | 流转：`{status, resolution?}` |

**校验**：title 必填 ≤256；description ≤8000；priority ∈ low/medium/high；code 空间内查重（重复 → 409 `CODE_DUP`）；doc_id 须为空间内存在的文档。
**权限**：仅空间成员可创建；流转权限——`open→claimed` 任何成员可认领（认领即分配）；`→fixed` 限作者/指派者/owner/admin；其余流转限作者/owner/admin。

### 1.3 状态机

```
open → claimed → fixed → closed   （可回退；fixed→open 返工必须附 resolution 说明）
```
