# B31 管理后台正文幅宽统一 + 侧栏标签树配色修复

- 日期：2026-09-30
- 性质：前端体验批（非上游协作内容线）
- commit：`52480237bb5ead312181776adde339e6e6710e3b`（代码段，parent `895fb013`，main 与 sync/ag-base 双写）

## 1. 背景与问题

用户反馈两条：
1. 管理后台 body 部分幅宽不一致——有的宽、有的窄、有的居中两边留空、有的靠左右边留空。
2. 侧栏「AI 助手」与「系统」之间的导航项文字看不清。

## 2. 诊断结论

### 2.1 侧栏中间项 = 「标签树」折叠面板
- 位置：`web/src/components/AppShell.vue` 的 `.tag-tree-head`（「AI 助手」按钮之后、「系统」分组之前），渲染 `{{ t('nav.kb.tagTree') }}`（中文「标签树」）。
- 根因：`.tag-tree-head` 颜色为 `var(--nav-text, rgba(235,238,245,0.82))`，而 `--nav-text` **全项目从未定义**，永远落到为深色侧栏设计的浅灰 fallback。浅色主题下该颜色与背景对比极低 → 文字近乎隐形。
- 修复：颜色改为 `var(--sidebar-text)`（`styles/tokens.css` 各主题均已定义该变量）。

### 2.2 22 个管理视图正文幅宽三派六种
实测根容器定义：
- 全宽左对齐（无 max-width，12 个）：an/dg/mt/og/pv/shares/sk/sm/tm/us/wd/files。
- 限宽左对齐（7 个）：drafts/impex/trash `max-width:1100px`、kb `1200px`、ib(ImBind)/settings `900px`、sk `960px`。
- 限宽居中（3 个）：bm `920px`、search `860px`、wv `1280px`。
- padding 也不统一（16~32px 顶、18~28px 侧、40~60px 底）。

## 3. 改动清单（23 文件）

- `web/src/components/AppShell.vue`：`.tag-tree-head` 颜色 `var(--nav-text,…)` → `var(--sidebar-text)`。
- 22 个管理视图根容器统一为 `max-width:1200px; margin:0 auto; padding:20px 24px 40px`，**全部居中、统一宽度**。
- 保留各视图特有属性：
  - `files-view`：`position:relative; min-height:100%`。
  - `wv-view`：`display:flex; flex-direction:column; gap:10px; height:100%; overflow:auto`。
  - `bm-view`：`width:100%; font-size:14px`。
- ⚠️ `.ib-view` 在 `ImBindView.vue`（max-width:900px 左对齐）与 `InboxView.vue`（无 max-width 左对齐）各自独立定义，本次分别统一为居中 1200px，无冲突。

## 4. 设计决策

用户确认策略：**全部居中、所有页面统一宽度（1200px）**。padding 一并标准化为 `20px 24px 40px`（此前顶/侧/底各异），消除视觉跳动。
